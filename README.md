# مسار (Masar) — نظام متكامل لتطوير الذات وإدارة الحياة

تطبيق ويب عربي (RTL) بلا خادم ولا حساب ولا مكتبات خارجية. يعمل بـ HTML وCSS وJavaScript عادي، وبياناته تُحفظ في `localStorage` داخل متصفحك فقط.

## الميزات

- **لوحة «اليوم»**: تقدم اليوم والأسبوع، عناصر اليوم (السجل، الصلوات، التحدي، العادات، الشاشة، الماء)، الأهداف النشطة، **المهام المتأخرة والتنبيهات**، واختصارات التسجيل.
- **أهدافي**: أهداف مخصصة بمجال وأولوية وموعد نهائي، مراحل ومهام (بمواعيد)، مؤشر رقمي (بداية/حالي/هدف)، مقارنة التقدم الفعلي بالوقت المنقضي، أرشفة، وسجل إنجازات.
- **عاداتي**: عادات يومية/أسبوعية أو عادات تقليل، تسجيل وتصحيح الأيام السابقة، السلسلة الحالية وأفضل سلسلة وأيام الانقطاع ونسب الالتزام (7 و30 يومًا). تعديل العادة لا يمسّ سجلها.
- **الصلاة**: خمس صلوات (المسجد/البيت/لم أصلِّ/مسح)، تسجيل أي تاريخ سابق، إحصاءات أسبوعية وشهرية، وسجل آخر 7 أيام. غير المسجَّل لا يُعدّ «تركًا».
- **وقت الشاشة**: إدخال يدوي مع الأوزان (TikTok×3، YouTube×2، الذكاء الاصطناعي×1، أخرى×1)، الإجمالي والموزون، حدود يومية قابلة للتعديل وتنبيه، ومقارنة باليوم السابق ومتوسط 7 أيام.
- **برنامج 300 يوم**: 10 مراحل × 30 يومًا (أكثر من 60 تحديًا مختلفًا)، تصاعد الصعوبة داخل المرحلة، تحدٍّ بديل، تخطٍّ/تراجع، سجل التحديات، ومراجعات أسبوعية وشهرية بملاحظاتك. برنامج تدريبي وليس علاجًا ولا يضمن نتيجة نفسية.
- **الماء**: عداد أكواب وهدف شخصي، تذكير بفاصل قابل للتغيير (تنبيه داخل الصفحة + إشعار متصفح عند السماح).
- **الأفكار اليومية**: أفكار أصلية من النظام (غير منسوبة لأحد) وأفكارك الخاصة. لا توجد اقتباسات منسوبة.
- **التحليلات والتقارير**: رسوم الوقت والمال والدراسة والشاشة والصلاة، «أنماط ومجالات تحسين» تُحسب من بياناتك فقط وبشروط حد أدنى للبيانات، وتقارير بفترات سريعة (اليوم/7/30/الشهر/الخطة) تتضمن مقارنة بالفترة السابقة وطباعة/PDF.
- **المظهر**: داكن وفاتح (يتبع النظام تلقائيًا في أول مرة)، متجاوب للهاتف والتابلت والحاسوب، لوحة المفاتيح، وتقليل الحركة عند طلبه.

## التشغيل
افتح `index.html` مباشرة، أو للأفضل من مجلد المشروع:
```bash
python -m http.server 8000   # ثم افتح http://localhost:8000
```

## النشر (GitHub Pages)
1. أنشئ مستودعًا وارفع كل الملفات: `index.html` `styles.css` `app.js` `enhancements.js` `life.js` `insights.js` `README.md` `LICENSE`.
2. من **Settings → Pages** اختر **Deploy from a branch** ثم `main` و`/(root)` واضغط **Save**.
لا حاجة لـ Node أو بناء.

## التحديث
استبدل الملفات بالنسخة الجديدة؛ البيانات تبقى لأنها في متصفحك (مفاتيح التخزين: `masar_goal_tracker_v1`، `masar_enhancements_v1`، `masar_life_v1`). حافظ على النشر من **النطاق نفسه** وإلا ستبدو البيانات فارغة (لكل نطاق تخزينه).

## النسخ الاحتياطي
- **JSON** (الإعدادات ← تنزيل نسخة): يشمل السجلات والإعدادات والعبادات والشاشة والتحديات والماء والأهداف والعادات.
- **CSV** (التقارير): السجل اليومي فقط.
- **الاستيراد**: يتحقق من الملف كاملًا قبل أي تغيير، ويرفض الملف التالف دون المساس ببياناتك، ويطلب تأكيدًا. نسخة قديمة بلا أهداف/عادات تُبقي الحالية كما هي.
- البيانات لا تنتقل بين الأجهزة تلقائيًا؛ استخدم JSON للنقل. مسح بيانات المتصفح يحذفها. التطبيق يذكّرك بالنسخ الاحتياطي إن مرّت 14 يومًا.

## القيود المعروفة
- لا يمكن لصفحة ويب قراءة وقت استخدام تطبيقات الهاتف؛ وقت الشاشة يدوي.
- تذكير الماء يعمل والصفحة مفتوحة فقط، وقد تُقيّد المتصفحات والهواتف المؤقتات في الخلفية.
- لا مزامنة بين الأجهزة ولا حسابات.
- تُحسب السلسلة الأسبوعية بأسبوع يبدأ الاثنين، وتُحسب السلاسل وفق جدول العادة الحالي.
- «تقدم اليوم» لمحة تقريبية بمتوسط العناصر وليس تقييمًا لك.
- تحتاج حوارات الأهداف/العادات متصفحًا حديثًا يدعم `<dialog>`.

## بنية المشروع
```text
index.html        الهيكل والأقسام
styles.css        التصميم والوضع الداكن
app.js            النواة: السجل اليومي، المؤشرات، الرسوم، التصدير/الاستيراد
enhancements.js   الصلاة، الشاشة، التحديات، الماء، الأفكار، المظهر
life.js           الأهداف المخصصة، العادات، لوحة اليوم والتنبيهات
insights.js       التقارير الموسعة، مقارنة الفترات، الأنماط
```
